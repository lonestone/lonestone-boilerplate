# Migration Intentions - v1.1.0

v1.1.0 is a draft of the next unpublished boilerplate release. It is **not** a git tag. A human still chooses the version, reviews, and merges the Release PR.

This folder is the daily-hygiene inventory for changes already on `main` since `v1.0.0` that did not land with an `unreleased/` intention. Feature PRs still write to `unreleased/`; those files are promoted here at release time (`adopt-conventional-commits`, `adopt-release-please`).

## Shipped without a consumer migration

- `install.sh` tty probe under `set -e` (new projects get it; existing projects already ran the installer).
- `.worktrees/` ignore paths for Knip, Oxlint, Oxfmt, and the i18n translation check.
- French documentation locale and French contribution/release pages (docs-only).
- Agent writing-rules copy in `AGENTS.md` / `CLAUDE.md` (producer/agent docs).
- Boilerstone explanation-page rewrites and the unreleased-intention workflow itself (producer process; consumers do not write intentions).
- Non-catalog app dependency bumps (NestJS, Sentry, AI SDK, and similar). Do not bulk-upgrade those from a generic intention.
