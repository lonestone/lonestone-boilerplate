# Migration Intentions - v1.1.0 (draft)

v1.1.0 is a **draft** next-release folder. It is not a published tag. A human still chooses the version, reviews this inventory, and stamps the changelog.

The unreleased work since `v1.0.0` is a TypeScript 6 compiler baseline, a new tested catalog constellation, a `cookie`/Astro hoist compatibility pin, and installer/knip typecheck fixes. Non-catalog app dependency bumps that landed with `pnpm upgrade -r` (NestJS, Sentry, AI SDK, and similar) are **not** a migration: do not bulk-upgrade those from this release.

## Shipped as baseline (no migration)

- `install.sh` tty-safe `/dev/tty` probing under `set -e` (new installs and onboard runs pick this up; already-onboarded projects do not re-run the installer).
- SPA French `loggedInSuccess` locale string (existing projects keep their own translations).
- Documentation/README mechanical corrections (oxlint/oxfmt, engines pins, Docker Compose services, `pnpm --filter=api` database scripts, generated OpenAPI filenames, removed dead schematics script). These apply only when creating a new project or when a human copies the docs.
- Recursive non-catalog package bumps in app `package.json` files. Consumers should not treat those as a single unbounded upgrade.
