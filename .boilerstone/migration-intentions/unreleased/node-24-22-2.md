# Upgrade Node.js to 24.22.2

## Goal

The project builds, tests and runs on Node.js 24.22.2 or a later 24 release.

## Why

Node.js 24.13 misses the security releases of March, June, July and October 2026. The October release fixes an out-of-bounds write in the zlib Brotli decoder and TLS hostname verification issues. An API that accepts compressed request bodies reaches the Brotli decoder.

## Applies When

- A Dockerfile, a CI workflow, a composite action default, `.nvmrc` or `engines.node` in `package.json` pins Node.js below 24.22.1.

## Do Not Apply When

- The project already runs a supported Node.js release that includes the October 2026 security fixes, such as 22.23.4, 24.22.1, 26.12.1 or later.

## Observable Gaps

1. **Docker images** — signal: `grep -rn "FROM node:24.13" --include=Dockerfile .` returns a match.
   Align with the staged reference Dockerfiles.
   Done when: every Node.js image in the project uses `node:24.22` or later.
2. **CI** — signal: a workflow or composite action under `.github/` pins Node below 24.22.1, including the `setup-node-pnpm` action default (`22.14.0` was left behind when workflows started passing 24.22.2).
   Align `node-version` and the defaults of `setup-env.yml` and `.github/actions/setup-node-pnpm/action.yml` with the staged references.
   Done when: no workflow or action default installs Node below 24.22.1.
3. **Local tooling** — signal: `engines.node` in the root `package.json` is below 24.22.1.
   Set it to `24.22.2`, along with `.nvmrc` when the project has one.
   Done when: `node -v` matches on a fresh checkout and `pnpm install` raises no engine warning.

## Out of Scope

- Any dependency upgrade, including `@types/node`.
- Moving to another major version of Node.js.

## Validation

- `pnpm lint` passes.
- `pnpm typecheck` passes.
- `pnpm test` passes.
- The Docker images build.
