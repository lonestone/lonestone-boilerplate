`@lonestone/boilerstone-cli` creates a project from the boilerplate, sets up your machine, and keeps the project in sync with later releases.

The map shows every command, what it reads and writes, and the order to run them in. Pick a flow to follow it step by step, or click a node to see what it does. The top is the boilerplate repository and the bottom is your project. Only the release passes from one to the other.

For why the upgrade system exists, read [Boilerplate upgrades](/lonestone-boilerplate/explanations/7_boilerplate-upgrades).
