---

Create a new project from the directory that should contain it:

```bash
pnpm dlx @lonestone/cli init my-project
```

`init` creates the project from the release matching the CLI version (the latest, unless you pin the CLI: `pnpm dlx @lonestone/cli@1.2.0 init my-project`), renames the workspace to `@my-project/*`, installs dependencies, and runs the setup script below. The directory name becomes the package scope, so use lowercase letters, digits and dashes.

When you join an existing project instead, follow these steps:

## 1. Prerequisites

Ensure you have the required tools installed:

- [Node.js](https://nodejs.org/) (version 24.13.0)
- [PNPM](https://pnpm.io/) (version 10.28.2)
- [Docker](https://www.docker.com/) and [Docker Compose](https://docs.docker.com/compose/)

You can use [fnm](https://github.com/Schniz/fnm) for managing your Node version:

```bash
fnm use 24.13.0
npm i -g pnpm@10.28.2
```

## 2. Install Dependencies

```bash
pnpm install
```

## 3. Run the Setup Script

```bash
pnpm rock
```

The setup script configures your local environment interactively. It will:

- Create the missing `.env` files from every `.env.example` (root, `apps/*`, `packages/*`)
- Prompt only for missing variables: database, application ports, SMTP (MailDev)
- Set up proper API URLs and trusted origins across all applications
- Optionally start Docker services (database, MailDev) and run database migrations

It never renames packages or deletes files, so it is safe to re-run.

## 4. Start Development

After the setup is complete, start the development servers:

```bash
pnpm dev
```

## Optional: Manual Setup

If you prefer to configure everything manually, you can:

1. Select which provided modules you do not need. Follow the according Explanations page to remove them cleanly
2. Manually copy and configure `.env` files from `.env.example` files
3. Start Docker services: `pnpm docker:up`
4. Run migrations: `pnpm --filter=api db:migrate:up`

For more details, check the [project's README.md](https://github.com/lonestone/lonestone-boilerplate/blob/main/README.md).
